MomoTranScript

Android 端侧离线对话长图 OCR 转录与结构化排版工具

MomoTranScript 是一款专注于对话截图长图与文档图像的本地文字识别与文本格式化工具。全部版面定位、文字行切分与 OCR 识别均在用户手机本地完成，无需注册账号，不上传任何图片与识别结果。

纯本地离线推理 零账号 · 零图片上传 自适应长图切窗 Android arm64-v8a

核心功能

  • 长图版面结构定位：自动按空白带自适应切窗，识别左右对话气泡、说话人、旁白、回复面板与插图区域。
  • 端侧文字识别与格式化：基于开源 MNN 推理引擎在设备本地运行 OCR 模型，自动整理为清晰的纯文本脚本与结构化 JSON 存档。
  • 批量目录与 PDF 抽取：通过 Android 系统文件选择器（PhotoPicker / SAF）读取用户主动授权的图片、文件夹或嵌入式图像 PDF，不申请全局存储权限。
  • 矢量打框对照与即时导出：支持逐页流式预览、文本在线校对、一键复制及导出为本地文件。
